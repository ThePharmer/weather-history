# Quickstart: Weather History App

## Prerequisites
- Node.js 18+
- npm 9+

## Setup

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```
    Access the app at `http://localhost:5173`

3.  **Run Tests**:
    ```bash
    npm test
    ```

## Project Layout

- `src/main.js`: Application entry point.
- `src/api/`: Contains `weather-api.js` for Open-Meteo interactions.
- `src/components/`: Contains UI rendering logic.
- `src/styles/`: Contains `style.css` for global styles.

## Key Commands

- `npm run build`: Build for production.
- `npm run preview`: Preview production build.
